# SC Leitor RS

App para Windows que lê os códigos de assinatura RS na tela do Star Citizen e mostra o mineral correspondente em uma pequena janela sobre o jogo.

## Download

Baixe a versão disponível em:
https://github.com/jhnario/SC-RS-Overlay/releases/latest

Na seção Assets, escolha o arquivo SC-RS-Overlay-main.zip.

## Como instalar

1. Baixe o ZIP e extraia todo o conteúdo para uma pasta.
2. Abra a pasta extraída e dê dois cliques em Iniciar.cmd.
3. Na primeira execução, aguarde a preparação automática. O app baixa o Python portátil e instala as dependências dentro da própria pasta.
4. É necessário ter internet nessa primeira instalação. Não feche a janela enquanto a preparação estiver em andamento.

Não é necessário instalar Python ou GitHub Desktop previamente.

## Aviso de segurança do Windows

Como o aplicativo não possui assinatura digital, o Windows pode mostrar um aviso ao executá-lo.

Se aparecer “O Windows protegeu o computador”:

1. Confira se você baixou o ZIP deste repositório.
2. Se confiar na origem, clique em “Mais informações”.
3. Clique em “Executar assim mesmo”, caso essa opção esteja disponível.

Não desative o antivírus. Se aparecer uma detecção de vírus ou ameaça específica, interrompa a instalação e envie uma captura do aviso para análise.

Lembrete: extraia todo o ZIP antes de abrir Iniciar.cmd.

## Como usar

1. Abra o Star Citizen e deixe um código numérico RS visível.
2. No menu (...) do app, selecione a opção para definir a área de leitura.
3. Delimite somente os números, deixando uma pequena margem. Evite incluir o ícone, distâncias ou outros textos.
4. Inicie a leitura pelo menu do app.

A área selecionada fica salva. Só será necessário ajustá-la novamente se mudar a resolução, o monitor ou a posição do código na tela.

Nas próximas vezes, basta abrir Iniciar.cmd.

## Atalho na área de trabalho

Execute CriarAtalho.cmd para criar um atalho do aplicativo.
Mantenha a pasta do app no mesmo local depois de criar o atalho.

## Se aparecer “Aguardando sinal”

Confira se o código numérico está dentro da área selecionada e legível.

Quando o jogo substitui o código pelo nome do mineral, o app pode voltar a aguardar um novo sinal.

## Limitações

A identificação usa uma tabela comunitária de assinaturas. Atualizações do jogo, sinais sobrepostos e falhas de leitura podem produzir resultados desconhecidos ou incorretos.

Projeto independente, sem vínculo oficial com a Cloud Imperium Games.
